### 📦 Key Architectures & Deployments

<details open>
  <summary>💻 <b>RestoSoft — Offline-First Desktop POS & Web ERP</b></summary>
  <br/>
  
  * **Offline-First billing:** Designed the main Windows desktop application using React, Electron, Node, and SQLite, allowing restaurant cashiers to process bills and KOT prints with *zero* active internet connection.
  * **LAN Architecture:** Designed a local networking layout where the primary cashier computer hosts a server to sync cashier terminals and waiter apps via local IP in real time.
  * **Bi-directional Cloud Sync:** Built a robust synchronization script that resolves conflicts and uploads data automatically once the internet restores.
  * **Hardware integration:** Configured direct silent thermal and network printing across multiple custom bill templates.
</details>
