### 💫 About Me

I am a passionate and result-oriented **Full-Stack Developer** with over **2.5 years of professional experience** building high-performance web applications and desktop software architectures. My engineering focus centers around creating robust, offline-first solutions, real-time data sync engines, and highly responsive user interfaces.

* 🚀 Currently working at **YoungMinds Technology Solutions** developing **RestoSoft** (an offline-first POS & restaurant ERP platform).
* 🛠️ Engineered a local LAN-based server synchronization network and built a resilient bi-directional cloud sync engine.
* 👨‍🏫 Resolved 150+ advanced web development queries as a **Subject Matter Expert** at Chegg India.
* ⚙️ I take full ownership of the product lifecycle—writing clean, secure, and maintainable code.

### 📦 Highlighted Deployments & Architecture

#### 🛒 **RestoSoft — Offline-First Desktop POS & Web ERP**
* **Desktop Platform:** Created a local-first application using React/TS, Electron, Node.js, and SQLite.
* **LAN Synchronization:** Designed a local network architecture where the main billing computer hosts a local server to sync multiple cashier terminals and waiter apps in real time.
* **Sync Engine:** Built a bi-directional custom database sync protocol to sync transactions to the cloud securely.
